# 🎹 문해찬(Pino)입니다.

> **사용자의 불편을 하나씩 해결해 나가는 개발자가 되고 싶습니다.**

현재 **우아한테크코스 8기 백엔드 과정**에서 배우고 있습니다.

코드를 잘 짜는 것도 중요하지만,  
요즘은 **“이걸 실제로 누가 쓰고, 뭐가 불편할까?”** 를 더 많이 고민하고 있습니다.

사용자를 직접 만나고,  
서비스를 만들어 보고,  
팀원들과 부딪히면서 배우는 중입니다. 🙂

<br/>

## 👨‍💻 요즘 하는 것

- 🚀 실제 사용자가 있는 서비스를 만들고 있습니다.
- 🗣️ 사용자에게 직접 물어보고 반응을 확인하는 걸 좋아합니다.
- 🤝 혼자 잘하는 것보다 같이 잘하는 방법을 배우고 있습니다.
- 🌱 사용자 가치를 만들면서 저도 같이 성장하고 싶습니다.
- 🤖 AI도 열심히 씁니다. 대신 제가 설명할 수 있는 코드를 만들려고 노력합니다.
